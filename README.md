# Trade-offs in Practice · 实践中的权衡

我带学生做AI4Mat（AI for Materials）有几年了，这个方向确实难学、也难教。我自己刚接触的时候也是完全摸不着头脑，概念本身并不深，问题是几个东西搅在一起，书本上基本不讲。

最直接的是AI演进太快。工具几个月就换一茬，等教材写出来、出版，用的东西已经变了。真有用的知识往往在实践者写的博客、笔记、issue讨论里，不在教科书里。

然后是学生的背景。材料专业出来的人对代码和AI普遍缺乏直觉。概念可以看书，但"手感"不行：什么时候该信任AI的输出、什么时候该警惕、碰到问题该坚持还是换思路，这些判断力书里教不了。

再往深一层，大概是两种认识论在较劲。材料学的方法论根基是假设—实验—表征—验证，追求机理、可重复、确定性。AI这边是概率的、黑箱的，每次运行都可能不一样。一个被训练成追求确定性的学生，每天要用本质上不确定的工具。至少在我这里，让学生先接受"这种不适感是正常的"、两种范式各有各的用场，比急着教具体工具更重要。

这三层难处背后是大量隐性知识，不在任何文档里，只从亲身踩坑中长出来。

"坑这个东西，少数人踩过就行了，不用每人都踩一遍。"这个项目的初衷，就是把我踩坑换来的隐性知识分享出来。

隐性知识写成空泛的建议等于白写。"要小心AI犯错"这种话谁都会说。这里的每篇记录都放在具体情境里：当时发生了什么、我怎么判断的、事后看哪里做对了、哪里走了弯路。

材料科学是我的主场，但怎么和智能体相处、怎么建立对AI输出的判断力，这些经验其实是学科无关的，对更广的AI for Science领域大概也有用。

说到底，隐性知识的核心是在什么情境下做什么取舍的判断力，所以我给这个仓库起名叫"实践中的权衡"。
