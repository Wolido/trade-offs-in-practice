# Trade-offs in Practice

用 AI 做科研、用智能体干活，本来应该是很有意思的事。但真上手就知道，像钓鱼或射箭：看着容易，里面的门道全是隐性的。甩网多远、拉弓多满，这些动作可以教、可以学。用什么饵、买什么扳指，这些经验没人带的话，自己连从哪开始都不知道。**有人领着玩，体验完全不一样。**

但大多数人身边没有这样的人。这个阶段刚把智能体用进科研的人，状态差不多：**迷糊着用，迷糊着让它做东西，出来的结果自己有时候也看不懂**。不少人觉得"跑起来了"就算成功，至于结果是好是坏，说不清。等到出了问题，比如输入稍微一改、输出就完全不对，才意识到事情没那么简单。我后来检查他们的配置才发现，**agent 里塞了大量没头没尾的上下文，对干活几乎没有帮助**。但最典型的画面还是这个：拿到科研或工作任务，下意识丢给一个自己控制不了的 agent，然后把结果交给我，我能明显看出里面 agent 失控的痕迹。**人本该是智能体的主人，现在反过来了，智能体牵着人的鼻子走。**

**这些不是某个学生的问题，是这个方向本身的难处。**

最直接的是AI演进太快。工具几个月就换一茬，等教材写出来、出版，用的东西已经变了。真有用的知识往往在实践者写的博客、笔记、issue讨论里，不在教科书里。

然后是学生的背景。材料专业出来的人对代码和AI普遍缺乏直觉。概念可以看书，但"手感"不行：什么时候该信任AI的输出、什么时候该警惕、碰到问题该坚持还是换思路，这些判断力书里教不了。

再往深一层，大概是两种认识论在较劲。材料学的方法论根基是假设—实验—表征—验证，追求机理、可重复、确定性。AI这边是概率的、黑箱的，每次运行都可能不一样。**一个学生要在短短一两年里，一边做材料研究，一边快速建立起对AI的直觉，这本身就很难**。对交叉学科来说，眼下是一个艰难的过渡时期：也许在AI繁荣时代出生成长的一代，会天然带着这种直觉；但现在的学生和从业者等不到那一天，他们需要的是一份显性化的知识，帮他们快速渡过这个时期。至少在我这里，让学生先接受"这种不适感是正常的"、两种范式各有各的用场，比急着教具体工具更重要。

这三层难处背后是大量隐性知识，不在任何文档里，只从亲身踩坑中长出来。**把它们显性化，就是这个项目在做的事。**

**坑这个东西，少数人踩过就行了，不用每人都踩一遍**。这个项目的初衷，就是把我踩坑换来的隐性知识分享出来。

材料科学是我的主场，但怎么和智能体相处、怎么建立对AI输出的判断力，这些经验其实是学科无关的，对更广的AI for Science领域大概也有用。

教程告诉你怎么做，这里记录的是为什么这么做。**什么情境下做什么取舍的判断力，正是隐性知识的核心——这就是 trade-off 的意思**。所以叫 Trade-offs in Practice。
